* Description :unfold:
Doom Emacs support for Aura on top of ~aura-lang~
(~editors/emacs/aura-lang.el~): ~aura-mode~, an inferior REPL, and ~aura lsp~
through lsp-mode or eglot.

Install, keys, configuration, and troubleshooting:
[[https://github.com/cybrid-systems/aura/blob/main/docs/editor.md][docs/editor.md]].

** Maintainers
Report issues at [[https://github.com/cybrid-systems/aura/issues][cybrid-systems/aura]].

** Module flags
- +lsp ::
  Start ~aura lsp~ in Aura buffers. The client is [[module::tools lsp]]:
  lsp-mode, or eglot with ~+eglot~.

** Packages
- [[package:aura-lang]]

/No hacks documented for this module./

* Installation
This module is not in Doom's module repository. Symlink or copy this
directory to ~$DOOMDIR/modules/lang/aura~ (both work, #5353). In ~init.el~
enable ~(aura +lsp)~ and ~:tools lsp~ (optional ~+eglot~), then ~doom sync~.

The recipe shipped in this module's ~packages.el~, and the key and
configuration tables, are in
[[https://github.com/cybrid-systems/aura/blob/main/docs/editor.md][docs/editor.md]].
